Project Overview -
This project for CIS 3755, Introduction to Information Visualization, visualizes ransomware attacks across the United States. Individual states can be clicked on to view additional information about ransomware activity in the area. Users can also filter the data by year (2020–2025) and by sector to better understand how different industries are affected over time. Each data breach is represented by an interactive pin that reveals breach details when hovered over. The goal of this tool is to highlight the importance of data protection, especially for individuals and organizations that rely heavily on digital systems.

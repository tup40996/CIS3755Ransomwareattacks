Project Overview -
This project visualizes ransomware attacks across the United States, allowing users to examine patters in data breaches by location and year. Users can filter the map by year to observe how breach activity changes between 2020 and 2025. Each data breach is represented by an interactive pin that reveals additional details when hovered on. The goal is to highlight the importance of data protection in everyday digital life, especially for individuals and organizations that rely heavily on digital systems.
